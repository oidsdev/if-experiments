# Distribution prospects, October 2026

Research only. Nothing in this file was submitted, posted, or sent. A person decides what to act on.

Checked 2026-10-10 against live pages. Forms and fees change. Open the URL again before using it.

## What this covers

**AI agent operators**

- [Oids](https://tryoids.com): public identity cards, a reputation score, and a public post feed for AI agents. Free to read. One API call to join. The signup response includes a key shown once.
- [Honeypot](https://honeypot-e6c.pages.dev): a free index of agent skills. Each skill is a `SKILL.md` added by pull request to `github.com/oidsdev/honeypot`. Machine-readable JSON at `/api/skills.json`. No sign-up. A stdio MCP server is published at `/mcp-server.py`.
- [House Rules](https://agent-house-rules.pages.dev): ten questions, then a short set of safety rules to paste into an agent. Free, no sign-up, runs in the browser. Nothing you pick leaves the device. The published page is written for Muse and Grok Bot. The same text can be pasted into another agent.
- [Agent Census](https://agent-census.pages.dev): an open, searchable dataset of publicly listed agents, bots, skills, and MCP servers. License on the page: CC-BY-4.0. Projects already in a public source the census covers are added on the next refresh. The other path they publish is to join Oids.

**Native-plant gardeners and stormwater-rebate seekers**

Both are [Rebate-Ready Garden](https://rebatereadygarden.com), published by Orbital Desk LLC.

A county plan is a PDF: a to-scale planting layout, a native plant list with sizes, quantities, and spacing, a compliance packet matched to that program's published rules, and an application submission sheet. Most editions are $19.50. Long Island editions are $24. The five-plan Prince George's bundle is $24.50. Separate DIY guides are $9, $12, and $39.

Editions on the site: Prince George's County, Montgomery County, Rockville and Gaithersburg, Washington DC, Fairfax County, and Long Island (Nassau and Suffolk, for the NEIWPCC Garden Rewards program).

These are reference layouts for a homeowner to adapt. They are not site-specific designs and not prepared by a licensed landscape architect. The program decides the rebate. If a plan does not match the program's published rules, the site says they will fix it or refund it. Downloads are refundable within 14 days if the plan has not been filed with an application.

The [free rebate database](https://rebatereadygarden.com/rebate-database) lists 23 residential programs across the Mid-Atlantic and Northeast. The page says it was checked September 30, 2026, with a few entries checked October 1. Some rows are marked UNVERIFIED. Confirm with the official source before applying.

Fairfax copy on the site already says the plans are not affiliated with or endorsed by VCAP, NVSWCD, or Fairfax County. Keep that disclaimer on any Fairfax mention.

## Left out on purpose

- Agent Checkout and AgentHaggle. Both are payment products.
- Pack Check. The published tool grades prompt packs and specifically flags trading-system language.
- Signed & Sealed. Life-paperwork kits, not these three audiences.
- Asking a county or grant program to endorse a paid plan. See the Chesapeake Bay Trust note below for the only ask that stays honest.

Do not quote a rebate dollar rate in public copy until this is checked: the free database says DC RiverSmart is $41 per square foot, confirmed against DOEE on October 1, 2026. Some DC plan cards on the homepage say $42. The drafts below do not quote a rate.

The company homepage still says "13 agents and counting" for Oids. The public feed is past that. These drafts do not use a count.

## How a row is scored

Fit is 1 to 5 for the audience that actually reads that place.

- 5: they are looking for this exact kind of thing, and there is a real submission path.
- 3: the audience overlaps, but the format is an article, a community post, or a paid slot.
- 1: wrong room.

### 5. Official MCP Registry

- URL: https://registry.modelcontextprotocol.io and the publisher guide in https://github.com/modelcontextprotocol/registry
- Type: directory operators and clients read
- Fit: 5 for the Oids remote MCP and the Honeypot stdio server. House Rules and Agent Census are not MCP servers.
- How to submit: install `mcp-publisher`, run `mcp-publisher init`, authenticate with `mcp-publisher login github` (namespace `io.github.oidsdev/...`), then `mcp-publisher publish`. A remote server can publish metadata with a `remotes` entry and no package. A PyPI or npm package has to prove ownership (`mcp-name` in the README or `mcpName` in `package.json`). GitHub auth only covers the `io.github.<user>` namespace.
- Draft description for Honeypot:

> Search a free index of agent skills and fetch a SKILL.md. Stdio server, Python standard library only. No account.

- Draft description for Oids:

> Read the public agent feed and use the Oids API. Remote MCP. Joining still takes the one-time API key from signup.

Glama's Oids connector page already points at `io.github.oidsdev/oids`. Publish under that same name if the namespace is yours.
